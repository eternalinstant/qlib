## 2. 模块职责

### 2.1 qlib_quant/ — 选股大脑

| 文件 | 职责 |
|------|------|
| `main.py update` | 从 Tushare 拉取 A 股日线/财务数据，写入 `factor_data.parquet` |
| `modules/modeling/predictive_signal.py` | LightGBM 模型训练 + 打分 + 选股，输出 `selections.csv` |
| `scripts/export_target.py` | 读取选股结果，取最近调仓日那批持仓，等权分配，输出 target JSON |

**Python 环境**：`qlib_quant\.venv\Scripts\python.exe`（装了 pyqlib）

### 2.2 qmt/ — 交易执行层

| 文件 | 层 | 职责 |
|------|-----|------|
| `config.py` | 配置 | MiniQMT 路径、IP/端口、会话ID、账户ID |
| `live_config.py` | 配置 | 仓位上限、滑点、风控参数、DRY_RUN 开关 |
| `qmt_data.py` | 封装层 | 封装 `xtquant.xtdata`：实时 tick、K线、交易日历 |
| `qmt_trade.py` | 封装层 | 封装 `xtquant.xttrader`：下单、撤单、查持仓/资产 |
| `target_portfolio.py` | 业务层 | 加载 target JSON、校验日期、股票代码归一化 |
| `rebalancer.py` | 业务层 | **纯计算大脑**：计算调仓订单，套用 A 股规则 |
| `live_trade.py` | 执行层 | 入口：预检 → 出计划 → 下单 → 等成交 → 写报告 |
| `scheduler/daily_signal.ps1` | 调度 | 08:30 触发：数据更新 + 打分 + 写 target |
| `scheduler/daily_trade.ps1` | 调度 | 14:25 触发：读 target + 调仓下单 |

**Python 环境**：`C:\Python312\python.exe`（装了 xtquant）

> 两个 Python 环境不能混用：选股用 `.venv`，下单用 `Python312`。

### 2.3 连接契约

```
qlib_quant  ──export_target.py──►  targets/target_YYYYMMDD.json  ◄──load_today_target()──  qmt
                                            │
                                    { date, strategy,
                                      invested_pct,
                                      positions:[
                                        {symbol, weight}
                                      ] }
```

- JSON 文件是两个子项目之间唯一的耦合点
- 日期必须 == 当天，否则拒绝执行（防陈旧文件）
- 股票代码统一用 `XXXXXX.SZ` / `XXXXXX.SH` 后缀格式


## 4. rebalancer 内部规则引擎

```
                    目标持仓 (target JSON)
                         │
                         ▼
              ┌─────────────────────┐
              │   计算目标股数        │   target_shares = floor(total_asset × invested_pct × weight / price, 100)
              │   vs 当前持仓        │   diff = target_shares - current_volume
              └──────────┬──────────┘
                         │
            ┌────────────┼────────────────┐
            │ diff < 0    │ diff = 0       │ diff > 0
            ▼            ▼                ▼
       ┌─────────┐  ┌─────────┐    ┌──────────┐
       │  卖出    │  │  不动    │    │  买入     │
       └────┬────┘  └─────────┘    └─────┬────┘
            │                             │
    ┌───────┴───────┐              ┌──────┴───────┐
    │ A 股规则检查   │              │ A 股规则检查  │
    ├───────────────┤              ├──────────────┤
    │ T+1 可卖量    │              │ 涨停不买      │
    │ can_use_volume│              │ 100 股整手    │
    │ 跌停不卖      │              │ 单笔金额上限  │
    │ 清仓含零股    │              │ 现金约束      │
    └───────┬───────┘              └──────┬───────┘
            │                             │
            ▼                             ▼
    ┌──────────────────────────────────────────┐
    │          卖出队列 + 买入队列                │
    │     (先卖后买排序，卖出回款可当日买入)       │
    └──────────────────┬───────────────────────┘
                       │
                       ▼
              ┌─────────────────┐
              │  换手率风控闸     │   turnover = 总成交额 / 总资产
              │  > 50% → 中止    │   全部买单金额 ≤ available_cash + 卖出回款
              └────────┬────────┘
                       │
                       ▼
                 计划订单列表
          [{symbol, side, shares, limit_price, reason}]
```

## 5. 安全防护机制

```
                        live_trade.py 入口
                              │
                 ┌────────────┴────────────┐
                 │                         │
          ┌──────┴──────┐           ┌──────┴──────┐
          │  kill-switch │           │   DRY_RUN    │
          │  文件级急停   │           │  配置级保护   │
          │             │           │              │
          │ qmt/STOP    │           │ live_config: │
          │ 存在 → 拒绝  │           │ True=不下单   │
          │ 一切下单     │           │ --live 覆盖   │
          └─────────────┘           └──────────────┘
                 │                         │
                 └────────────┬────────────┘
                              │
                    ┌─────────┴─────────┐
                    │  preflight() 预检  │
                    │  · 交易日？        │
                    │  · 交易时段？       │
                    │  · 账户已登录？     │
                    └─────────┬─────────┘
                              │
                    ┌─────────┴─────────┐
                    │  下单时风控        │
                    │  · 换手率 ≤ 50%    │
                    │  · 单笔 ≤ 20万     │
                    │  · 超时撤单重试     │
                    │  · 幂等（调到目标）  │
                    └───────────────────┘
```

| 机制 | 触发条件 | 效果 |
|------|---------|------|
| kill-switch | `qmt\STOP` 文件存在 | 拒绝一切下单 |
| DRY_RUN | `live_config.DRY_RUN = True` | 只算计划不下单；`--live` 可覆盖 |
| 交易日守卫 | 非交易日 | 中止退出 |
| 时段守卫 | 非交易时段（且非 dry-run） | 中止退出 |
| 账户检测 | 未登录 / 无账户 | 中止退出 |
| 换手率风控 | 一次调仓换手 > 50% | 中止不下单 |
| 单笔限额 | 单笔 > 20万 | 缩量到上限 |
| 超时撤单 | 30秒未成交 | 撤单 → 重算残差 → 重报（最多2轮）|
| 幂等 | 目标已达成 | 零下单 |

## 7. 当前策略参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 策略 | `alpha158_momentum_volume_k6_dd10_overlay` | 量价动量，CSI300 池 |
| 模型 | LightGBM | 5 个特征 (ROC20, RSV20, RANK20, CORD20, VSUMD20) |
| 调仓频率 | biweek（双周） | 每 2 周换一次持仓 |
| 持仓数量 | topk=6 | 每次 6 只股票 |
| 总仓位 | 80% | 留 20% 现金 |
| 分配方式 | 等权 | 每只约 16.67% |
| 滑点 | 30bps (0.3%) | 买高卖低以求成交 |
| 下单超时 | 30 秒 | 超时撤单重报 |
| 最大重试 | 2 轮 | 撤单后重新出计划 |
