# 策略命名词典（看懂策略名）

策略名是一套**编码缩写**拼起来的，比如 `push25_cq10_k8d2_very_tight` =
「push25 系列 · 现金流质量10因子 · 选8只每期换2只 · 极紧回撤控制」。
查下面的词典即可解码任意策略名。文件位置：`strategy/configs/models/`（模型策略）、`strategy/configs/strategies/`（因子策略）。

---

## 一、因子 / 特征来源

| 编码 | 中文含义 |
|---|---|
| `alpha158` | Alpha158 量价技术因子集（Qlib 内置 158 个技术指标） |
| `cq10` / `cq9` | 现金流质量（cashflow-quality）10 / 9 因子 |
| `qvf` | 质量+价值因子（Quality-Value-Factor） |
| `core12` | 12 因子核心集（质量/价值/现金流基本面 + 动量/排名） |
| `hybrid8/9/10` | 混合 N 个因子（量价 + 基本面） |
| `6p3a` | 6 个基本面因子 + 3 个 alpha 技术因子 |
| `momentum_volume` / `momentum5` | 量价动量（5 日动量） |
| `combo_only` | 仅用合成/组合因子 |
| `ic_filtered` / `ic_strong` | 按 IC（信息系数）筛选 / 只留强 IC 因子 |
| `fund` / `fundamental` | 基本面因子 |
| `tech_core` | 技术核心因子 |
| `book_enhanced` | 加强账面价值（book-to-market）因子 |

## 二、选股参数

| 编码 | 中文含义 |
|---|---|
| `k6` / `k8` | 选股数 topk = 6 / 8 只 |
| `d2` / `d0` | 换手限制：每期最多换 2 只 / 不限制 |
| `n320` | 模型参数变体（约 320，树数/样本规模档） |
| `csi300` / `csi800` | 股票池：沪深300 / 中证800 |
| `size_neut` | 市值中性化 |

## 三、风控 / 仓位（overlay 叠加层）

| 编码 | 中文含义 |
|---|---|
| `overlay` | 风控叠加层（波动率/回撤/趋势 控仓） |
| `dd10` | 回撤控制阈值 10% |
| `very_tight` / `tight` / `balanced` / `robust` | overlay 参数组：极紧 / 紧 / 平衡 / 稳健（回撤控制强度递减） |
| `vol_norm` | 波动率归一化权重（低波动股给更高权重） |
| `bull_release` / `market_trend_release` | 牛市/趋势向好时释放仓位（加仓） |
| `sticky` / `sticky0` | 持仓粘性（减少换手）/ 无粘性 |
| `pos100` / `fixed80` | 满仓 100% / 固定 80% 仓位 |

## 四、频率 / 模型 / 其他

| 编码 | 中文含义 |
|---|---|
| `daily` / `biweek` / `week` | 日频 / 双周 / 周频 调仓 |
| `lgb` / `lgbm` / `catboost` | LightGBM / CatBoost 模型 |
| `10d` / `20d` | 标签为预测未来 10 / 20 日收益 |
| `walkforward` / `wf` | 滚动前推验证 |
| `v2` / `v3` | 版本迭代 |
| `compact3` | 精简到 3 因子 |
| `_base` | 基础模板 |
| `push25` | 实验系列代号（QVF+质量+现金流因子的迭代版本） |

## 五、生产 / 关键策略（大白话）

| 策略名 | 大白话 | 业绩（OOS） |
|---|---|---|
| `qvf_alpha158_core12` | **核心12因子主力**：质量+价值+现金流基本面 + 动量/排名，双周选股 | 年化 20.0% / 回撤 -11.3% / 夏普 1.12 |
| `alpha158_momentum_volume_k6_dd10_overlay` | **量价动量主策略**：偏行为金融，选 6 只，10% 回撤控制 + 风控叠加 | 主备组合的主腿 |
| `push25_cq10_v3_vol_norm` | **质量现金流备策略**：偏质量/价值/现金流，波动率归一化权重 | 主备组合的备腿 |
| `push25_cq10_k8d2_very_tight` | **质量现金流单策略最优**：选 8 只每期换 2 只，极紧回撤控制 | 年化 26.04% / 回撤 -8.56% / 夏普 2.09 |
| **主备 60/40 组合** | **阶段一最终方案**：60% 量价动量 + 40% 质量现金流 | 年化 23.19% / 回撤 -7.81% / 夏普 1.849 |

> 提示：策略名本身**不建议重命名**——749+ 个配置的文件名被回测结果目录、脚本、引用大量依赖，改名会全断。看不懂时查本词典即可。
